# 衍生視界：免費期權籌碼與權證篩選

個股權證發行與分點（#warrant-directory）：依官方上市、上櫃公司名單建立個股認購／認售名錄，逐檔標示發行資料日期、缺欄與實際分點覆蓋。沿用每日排程；名錄收錄不代表取得所有分點。

近月現股與權證關聯 #warrant-relationship：按個股逐日比較未還原現股收盤、認購／認售成交量、相同樣本量變、當日履約條款與部分分點紀錄。歷史上櫃條款與分點不足日期逐日標示，不將現在條款倒套舊資料。分點連續買超、雙邊買超、近到期賣超與長天期買超僅為策略線索，不識別大戶或確認其持倉。每日沿用既有免費來源更新最近一個月；相關係數為短期描述，非預測、套利或交易獲利驗證。

權證每日追蹤報告 #warrant-report：同日價量、分點持續買賣／方向反轉、發行條件與訊號後續觀察。價量覆蓋與分點清單分開計數；分點未入榜不填零，連續訊號遇缺日期即中斷。每版保存規則、來源日期與修訂摘要，舊版本不覆寫。啟用後封存與歷史放量研究分開呈現，首個後續交易日收盤作基準，觀察其後1／3／5／10交易日；價格變化非成交或扣費後報酬，也不是已驗證即時樣本外績效。既有行情與分點排程完成後重建日報，無新增付費來源或模型呼叫。

台灣期權、權證；美國 CFTC 週報、Cboe 選擇權統計與 CFE 期貨結算價。每日觀察保留權證及其標的收盤價最近 60 個資料日；不抓現股分點。另有富邦權證分點排行（非全部分點）。

行情與分點實際執行時間分別見首頁及資料與更新；雲端備援工作在漏跑時補觸發，兩者皆由公開儲存庫標準 Ubuntu runner 執行，使用 Python 標準函式庫；無 API 金鑰、付費主機、付費行情、cache 或 artifacts。行情內容相同時保留原內容與時間，另發布實際檢查紀錄；已成功部署的同一版本不重建，先前失敗或尚未部署時會重試。GitHub Pages 免費託管，排程可能延遲或漏跑，並非準時更新保證；實際資料日與來源狀態以頁面為準。共用寫入群組允許排隊，同版本短時間內成功的重複檢查會略過。

資料源：臺灣期交所、證交所、櫃買中心、CFTC、Cboe。CFTC 為週報，日排程只檢查新發布；不含 CME 全行情或美股完整選擇權鏈。本站為整理後資料，各項資料日與更新狀態在網站標示；來源失敗保留最後成功值。台灣日資料超過 4 個交易日提醒；年度日曆加上證交所臨時休市公告，日曆更新失敗保留已核實版本，未知年份停止新鮮度判斷。美國日資料仍採 4 個日曆天、CFTC 週報採 14 個日曆天。法人歷史自啟用後累積最近 60 個資料日。非即時行情，僅供研究。

權證價差異常觀察：每日依同日、同標的及相同基本履約條件配對，按行使比例換算收盤價。配對資料保留 252 個資料日，每期條款獨立保存；前 20 筆資料估算 Z 值，|Z|≥2 才列訊號。訊號後次一資料日作觀察基準，再觀察 5 個資料日的偏離收斂；屬收盤價差事件回測，沒有可成交套利、交易報酬或成本後損益的推定。資料不足、缺值與失敗另行標示。

價差回測的上市歷史補抓：官方最近一個月的歷史行情／條款與認購、認售成交量逐日核對後匯入。較早區段僅納入有 MOPS 生效調整公告、且與保存條款核對通過的權證，存在樣本選擇偏差；不把最新條款倒套舊價。資料涵蓋、無報表日期與失敗原因見價差頁面及 data/derivatives/warrant-backfill.json；上櫃及分點排行未補抓；標的價格僅採同日報表明列且代碼吻合者。完整日報區段的條款依各日報表（發行人前一營業日申報）；較早區段依生效公告。來源可能修訂，未另驗證盤中條款異動。

權證分點來源：富邦證券公開網站／嘉實資訊；買超與賣超各最多 15 名，非全部分點。實際檢查時間見首頁；在成交量前 300 檔＋固定清單的原總量上限內，保留跨日未完成項目與今日熱門名額（設定見 automation/derivatives/warrant-branches.json）。每檔最多累積 30 個資料日。未列入不代表零交易，不查現股。

資料品質與驗證：#quality 顯示來源品質、時間戳、發布內容校驗碼及最近檢查紀錄；治理規則隨免費日排程執行。收盤價差回測維持 Walk-forward Research，正式模型資格為否、Live OOS 為 0；歷史修訂可重算，不冒充即時績效。

個股權證每日觀察表：#warrant-daily 按標的整合權證及標的同日期漲跌、成交量增減與量變率、同條件收盤價差、到期剩餘日曆天數及 8 項欄位完整度。讀取既有免費日更新資料，不新增網路來源或付費服務；支援排序、篩選、CSV 與逐檔趨勢連結。

個股權證量價日報 #warrant-volume-report：已補齊 2026-10-07 至 2026-11-06 的 20 個交易日日報，另列 11 個休市日。使用上市及上櫃官方每日價量與同日標的價格，先補五個交易日作均量基準；無成交、五日資料不足與均量為零各自標示並排除比較。每日依標的列出放量認購／認售檔數及占可比較權證比例。歷史個股分類採 2026-11-06 官方公司名錄回查，先前已退出名錄的標的涵蓋未驗證；官方歷史資料可能修訂。量價日報未回填歷史履約條款、分點或模擬成交。涵蓋狀態見 data/derivatives/daily-reports/warrant-volume/coverage.json；沿用免費每日排程保留歷史並新增當日日報。

權證自動試驗 #warrant-lab：上市權證、八個獨立虛擬帳戶（自動選用＋七個固定候選），每戶 10 萬元；依同一日排程記錄後續資料，不回填歷史成交。成本與滑價為明示假設，至少累積 61 個新資料日後，每 20 期檢查候選；通過樣本、分段報酬、回撤及成本壓力門檻才影響後續新單。無券商連線或 AI 呼叫，無獲利保證。策略觀察報告每天保存 HTML 與 JSON，同日內容變更另存版本；舊帳戶與 v1 封存保留，新候選明列開始日期並核對共同比較區間。

手動更新：Actions → derivatives-daily → Run workflow。每日重點觀察 #warrant-focus 由同一免費日排程產生：前五期均量至少 2 倍且 100 張、價差 |Z|≥2；較大價差另列待觀察，不混充異常。

本機更新：`python automation/derivatives/collect.py`。工作流程核對 Pages 最新 build 與 HEAD，必要時明確呼叫 build API。

市場篩選預設下載成交量前 2,000 檔，需要時載入全市場。個股觀察表的前次成交價與前筆成交量基準寫入行情分檔，不需要下載整包歷史。權證按標的載入 `warrant-catalog.json` 與 `warrants-by-underlying/<代碼>.json`；完整市場清單須明確選取。保留完整 `warrants.json` 供分點 collector、離線工具與舊版相容。只發布 JSON，由 GitHub Pages 透過 HTTP 壓縮傳輸，不再另存或請求 `.json.gz`。既有 Git 歷史不改寫。
